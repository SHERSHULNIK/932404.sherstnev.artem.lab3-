
# Лабораторная работа №3

## Тема

Искусство и креатив: хобби и любимые места.

## Выполненные требования

- На существующую страницу добавлены секции «Мои хобби» и «Любимые места».
- В секции хобби размещены три карточки: рисование, фотография и видеомонтаж.
- Для карточек используются изображения из папки `images`.
- Карточки хобби выровнены с помощью Flexbox; изображение и описание расположены рядом.
- Для любимых мест добавлена сетка из шести карточек на основе CSS Grid.
- Изображения мест размечены семантически с помощью `<figure>` и `<figcaption>`.
- Краткие описания хобби и мест оформлены в элементах `<p lang="ru">`.
- Сетка карточек отображает три колонки на широком экране, две на планшете и одну на мобильном устройстве.
- Сохранены исходные секции «Навыки», «Проекты» и «Обратная связь», шапка, контакты и анимация подсветки секций.
- В списке любимых мест вместо лесной тропы добавлен фитнес-зал.
- Текст размещён под фотографиями на светлом фоне, поэтому он не накладывается на изображения.

## Структура страницы

Страница содержит исходные блоки с информацией об авторе, навыками, проектами и обратной связью, а также добавленные секции с хобби и любимыми местами.
